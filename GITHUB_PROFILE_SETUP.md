## Profile README

GitHub profile READMEs require a **public repository named exactly `BTheCoderr`** under the `BTheCoderr` account.

1. Create a new public repository named `BTheCoderr`.
2. Initialize it with a README.
3. Replace that README with the contents of [GITHUB_PROFILE_README.md](./GITHUB_PROFILE_README.md).
