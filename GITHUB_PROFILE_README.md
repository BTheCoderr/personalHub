## How I build

I care about the parts that turn a demo into a usable product:

- clear product flows instead of disconnected screens
- auth and ownership that work across devices
- least-privilege data access and RLS
- failure states and recovery paths
- responsive mobile behavior
- testing around the flows users actually depend on
- AI integrations with fallback paths instead of one-provider lock-in
- honest README/status documentation that says what is live, what is beta, and what is still planned

I am especially interested in **React / React Native product work where the job is to fix, finish, and ship**.
